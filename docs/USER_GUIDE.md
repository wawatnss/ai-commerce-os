# Guide utilisateur — AI Commerce OS v1.0.0-beta

AI Commerce OS vous permet de générer des boutiques e-commerce complètes en quelques minutes, sans écrire de code.

## 1. Créer votre compte

1. Ouvrez l'admin : `https://admin.votredomaine.com`
2. Cliquez sur **S'inscrire**.
3. Renseignez votre email et un mot de passe.
4. Vérifiez votre email en cliquant sur le lien reçu (si SMTP configuré).

## 2. Créer votre première boutique

1. Depuis le tableau de bord, cliquez sur **Créer une marque**.
2. Remplissez le formulaire :
   - **Nom de la boutique** : le nom principal (ex. "EcoFit")
   - **Catégorie** : fitness, cuisine, tech, etc.
   - **Objectif** : conversion, notoriété, lancement rapide
   - **Budget** : starter, growth, scale
3. Cliquez sur **Générer**.
4. Attendez 10 à 30 secondes. Le moteur génère :
   - La marque
   - Le produit
   - Le fournisseur
   - La page d'accueil
   - Les CTA
   - La FAQ
   - L'identité visuelle (palette, typographie, prompts d'images)

## 3. Vérifier la qualité

1. Cliquez sur votre marque dans le tableau de bord.
2. Consultez les scores :
   - **Validation score** : qualité globale
   - **Readiness** : publication possible
   - **Shopify readiness** : compatibilité Shopify
3. Si le score Shopify est trop bas, cliquez sur **Auto-fix**.

## 4. Optimiser

1. Ouvrez la page de votre boutique.
2. Cliquez sur **Optimiser** pour lancer le moteur de conversion.
3. Le moteur améliore les textes, les prix, les avis et les appels à l'action.

## 5. Exporter

1. Sur la page de la boutique, cliquez sur **Exporter**.
2. Choisissez le format :
   - **JSON** : blueprint générique
   - **Shopify** : fichier compatible Shopify
3. Téléchargez le fichier.

## 6. Gérer votre compte

- **Modifier l'email** : Profil > Paramètres
- **Changer le mot de passe** : Profil > Sécurité
- **Supprimer le compte** : Profil > Danger zone (supprime aussi vos boutiques)

## 7. Gérer votre abonnement

- Le plan **Free** permet 3 boutiques.
- Le plan **Pro** permet 25 boutiques, 10 exports et 500 crédits IA.
- Le plan **Business** est illimité avec 5000 crédits IA.
- Pour upgrader, cliquez sur **Billing** dans le menu admin.
